# Проверки версии 5

Проведено 20 октября 2026.

## Результат

`npm test`: 13 тестов, все успешны.

- Подпись Telegram: действительная, подменённая, просроченная, дата из будущего, повторяющиеся параметры.
- Закрытый по умолчанию доступ мастера, запрет клиентской записи настроек и фото.
- Цена/длительность с сервера, нормализация телефона, идемпотентность создания.
- Пересечение длинных услуг, соседние интервалы, конец дня, прошлые/неоткрытые окошки.
- Принадлежность записи, ограничение 12 часов, отмена и перенос.
- Отсутствие чужих контактных данных и заметок в ответе клиентке.
- Восемь одновременных вызовов создания: один успех, семь конфликтов.
- Транзакционная очередь сообщений, отмена старых задач при переносе/отмене.
- Защита webhook и cron секретами, конфликт версии админских изменений.

SQL-интеграционные тесты используют PGlite (PostgreSQL в WASM) с адаптером пула на одно соединение. Это проверка SQL и транзакционных сценариев, а не нагрузочный тест отдельного Supabase с несколькими соединениями. Конкурентный тест дополнительно сериализуется адаптером; проверку блокировки строки на настоящем хостинге нужно повторить при подключении.

`npm run test:ui`: успешный прогон в headless Chromium, viewport 390×844.

- Главная, выбор даты/времени, услуги, имя/телефон и экран успешной записи.
- «Мои записи», перенос и отмена.
- Пять вкладок мастера, новый расход, настройки студии.
- Преобразование фото и запрос загрузки, ручная запись.
- Нет ошибок JavaScript; строка с HTML в имени не создаёт исполняемый DOM-элемент.

В браузерных тестах Telegram и HTTP API подменены фикстурами; серверные правила вызываются в тестовом обработчике. Уведомления Telegram в SQL-тестах также подменены. Реальных сообщений не отправлялось.

## Не проверено без подключений

Публикация Vercel, соединение с конкретным Supabase, фактическая загрузка Storage, регистрация webhook через BotFather, отправка/доставка Telegram и выполнение Supabase Cron. Для этого нужны значения `.env.example` и отдельный проверочный запуск после развёртывания. Приложение не заявляется как уже запущенное.

## Воспроизведение

```bash
npm ci
npm test
npm run test:ui
```

По умолчанию UI-тест использует Linux Chromium из dev-зависимости. Для другой системы или уже установленного браузера укажи абсолютный `CHROMIUM_PATH`. На текущей машине архив браузера пришлось распаковать без восстановления владельцев файлов; исходники приложения это не затронуло.
